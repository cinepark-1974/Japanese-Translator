# 🎌 Japanese-Translator v2.0

### BLUE JEANS PICTURES — 5-Stage Market Adaptation Pipeline

한국어 시나리오를 **일본 프로듀서가 "우리 관객한테 통한다"고 느끼는 일본어 시나리오**로 변환하는 AI 번역 엔진.
단순 번역이 아닌 **문화코드 변환 → 경어 설계 → 시나리오 포맷 변환 → 대사 현지화 → 품질 검증**까지 5단계 파이프라인을 실행합니다.

> **언어 변환이 아닌 시장 변환(Market Adaptation)**

---

## ⚠️ v2.0에서 무엇이 바뀌었나

v1.x는 원고를 **글자 수**로 잘라 호출했습니다. 씬 한복판에서 배치가 갈렸고, 출력 토큰 한도가 입력보다 작아 뒷부분이 조용히 잘렸습니다. 그 결과 「상속」 일본어판이 **원문의 41% 분량**에서 끊긴 채 완성본으로 나갔습니다.

v2.0은 그 구조를 바꿉니다.

| | v1.x | v2.0 |
|---|---|---|
| 분할 기준 | 글자 수 8,000자 | **씬 경계 (기본 4씬)** |
| 출력 한도 | `max_tokens` 8,000 고정 | **입력 길이 × 3 동적 산정** |
| 절단 감지 | 없음 | **`stop_reason` 확인 → 즉시 경고** |
| 호출 간 표기 통일 | 없음 | **고정 용어집 매 호출 주입** |
| 출고 전 검증 | 없음 | **VALIDATION GATE** |

## 🚀 5-Stage Pipeline

| Stage | 이름 | 모델 | 역할 |
|-------|------|------|------|
| **1** | Raw Translation | `claude-sonnet-5` | 한국어 → 일본어 충실한 직역 + 캐릭터명/장소명/통화 매핑 |
| **2** | Format Conversion | 규칙 기반 (무료) | 한국 시나리오 포맷 → 일본 〇柱 / ト書き / 「」セリフ 변환 |
| **3** | Voice Rewrite | `claude-opus-5` | 번역체 제거, 일본 시나리오 문체로 리라이팅 |
| **4** | Dialogue Polish | `claude-opus-5` | 경어 설계 적용, 캐릭터별 대사 현지화 |
| **5** | QA Check | `claude-sonnet-5` | 포맷/경어/문화코드/분량/스토리 검증 + 점수화 리포트 |

각 단계는 독립 실행됩니다. 중단해도 결과가 세션에 남고, JSON 백업으로 다음 날 이어서 진행할 수 있습니다.

### English Translator Engine과의 차이

| 항목 | English Translator | Japanese Translator |
|------|-------------------|---------------------|
| 핵심 과제 | 언어 변환 | **시장 변환** |
| 호칭 체계 | 평탄화 (first name) | **5단계 경어 설계** |

| 통화 | 직역 또는 USD | **1/10 고정 변환 (원→엔)** |

## 📚 입력 자료 3종

### 1) 고정 용어집 JSON — 권장

작품별 확정 표기를 구조화한 파일입니다. 인물·조단역·지명·법령·금액을 한 번에 읽습니다.

```json
{
  "characters": [
    { "ko": "한석훈", "ko_short": "석훈", "ja": "神崎遼",
      "yomi": "かんざきりょう", "cue": "神崎" }
  ],
  "minor":  [{ "ko": "기자", "ja": "記者" }],
  "places": [{ "ko": "서울지방국세청", "ja": "東京国税局" }],
  "law":    [{ "ko": "상속세 및 증여세법 제73조 (물납)", "ja": "相続税法第四十一条（物納）" }],
  "money":  [{ "ko": "1억 원", "ja": "一千万円" }]
}
```

`cue` 가 **대사 헤드**입니다. 엔진은 `神崎遼` 에서 `神崎` 를 빼고 남은 `遼` 를 **금지 표기**로 등록해, 대사 헤드에 이름이 쓰이면 검출·치환합니다.

값에 한글이 섞인 항목(예: `환산 기준`)은 매핑이 아니라 설명문이므로 자동 제외됩니다.

### 2) 고정 용어집 MD — 표기 흔들림 방지의 핵심

업로드하면 **매 API 호출의 시스템 프롬프트 맨 뒤에 통째로** 들어갑니다. 프롬프트 내 다른 지시와 충돌하면 용어집이 우선합니다.

대화 이력이 아니라 시스템 프롬프트라, 배치가 26개로 나뉘어도 모든 호출이 같은 표기를 봅니다. 6KB 정도라 토큰 부담도 미미합니다.

### 3) 한·영·일 대조표 XLSX

시트명과 헤더명을 키워드로 자동 인식합니다. **일본어 열이 없는 시트(영문 전용)는 자동으로 건너뜁니다.** 한·영·일 통합 대조표를 그대로 올리면 됩니다.

| 시트명 예시 | 분류 | 인식 키워드 |
|---|---|---|
| 한·영·일 이름 대조 | 주요 인물 | (그 외 전부) |
| 조·단역 한영일 | 조·단역 | 단역 · 조역 · 조연 |
| 일본판 지명·기관·고유명사 | 지명·기관·용어 | 지명 · 기관 · 장소 · 용어 · 명칭 · 고유명사 |
| 일본판 법조문 | 법조문·직급 | 법조문 · 법령 · 법률 · 조문 · 직급 |

| 열 | 인식 키워드 | 용도 |
|---|---|---|
| 한국명 / 한국판 원문 | 한국명 · 한국판 · 원문 | 치환 대상 |
| 일본명 (한자) / 일본판 (확정안) | 일본명 · 일본판 · 일본어 | 확정 표기 |
| 요미가나 | 요미가나 · 読み | 표시용 |
| 대사 헤드(일) | 대사 헤드 · cue | 극중 호칭 |
| 약칭 | 약칭 | 다른 시트에 있어도 교차 참조 |
| 경어태그 | 경어 · 톤 · keigo | keigo / teinei / tameguchi / kenson / ibar |

`역할 (일본판)` `비고` `대응 정확도` 처럼 표기가 아닌 열은 매핑에 쓰이지 않습니다. 일본어 값 뒤의 한글 전용 괄호·대시 주석은 자동 제거됩니다.

### 4) CSV / TXT 인물표 — 간이

```
# CSV — 한국이름, 일본이름, 경어태그, 호칭메모(선택)

박성태,杉山正道,ibar,タメ口+命令形

# TXT
김지훈 → 中村智弘 → teinei
```

## 🎬 씬 단위 배치 실행

원고를 **씬 경계로만** 자릅니다. 한국 원고의 씬 헤딩 패턴 5종을 자동 판별합니다.

| 패턴 | 예시 |
|---|---|
| INT./EXT. | `INT. 국세청 사무실 - 아침` |
| S#번호 | `S#12. EXT. 한강 둔치 - 밤` |
| 씬 번호 | `씬 7. 실내. 조사실` |
| 번호+장소 | `12. 실내. 아파트 - 낮` |
| 〇 (일본식) | `〇東京国税局・資産課税課（午後）` |

```
씬 패턴 'INT./EXT.' · 총 102씬 → 26배치 (4씬씩)
```

### 출력 토큰 동적 산정

| 배치 입력 | 출력 한도 |
|---|---|
| 1,000자 | 8,000 토큰 |
| 3,000자 | 9,000 토큰 |
| 8,000자 | 24,000 토큰 |
| 30,000자 | 64,000 토큰 |

입력 1자당 3토큰을 확보합니다. 하한 8,000 / 상한 64,000 토큰입니다.

### 절단 감지

매 호출의 `stop_reason` 을 읽습니다. `max_tokens` 면 **그 자리에서 빨간 경고**가 뜹니다. 배치별 입력/출력 씬 수도 대조해 리포트로 남깁니다.

### 배치 간 문맥 전달

직전 배치 결과의 마지막 250자를 다음 호출에 참고용으로 넘깁니다. 표기·경어 레벨·문체가 이어집니다. 전문을 붙이지 않으므로 컨텍스트가 비대해지지 않습니다.

## 🚦 VALIDATION GATE — 출고 전 검증

원본 한국어 원고와 번역 결과를 대조합니다.

| 항목 | 기준 | 판정 |
|---|---|---|
| 씬 수 | 오차 **0** | 실패 시 출고 금지 |
| 본문 글자 수 | 원본의 **85% 이상** | |
| 대사 줄 수 | **±5%** | 초과 시 경고 |
| 금지 표기 | **0건** | 이름 표기가 대사 헤드에 쓰였는지 |

```
씬 수      원본 102 → 번역 59   -43   실패
금지 표기  31건 / 6종                 실패
```

대사 줄 수는 한국 원고 서식에 따라 두 가지 패턴(인물명 줄 + 대사 줄 / `인물명: 대사`)을 모두 시도해 더 많이 잡히는 쪽을 씁니다. 어느 패턴을 썼는지 화면에 표시됩니다.

### 탐지 패턴 10종

한글 원문 · 카타카나 한국 지명(ソウル·セジョン·ノウォン) · 카타카나 한국식 인명(キム·パク) · 한국식 호칭(オッパ·ヒョン) · 원화(ウォン·₩) · 로마자 한국 지명 · 한국 법령명 직역(相続税及び贈与税法·国税基本法) · 한국식 사건번호(고합) · 한국식 공무원 급수(9級) · 미현지화 문화어

기계 치환은 대조표에 있는 항목만 건드립니다. 긴 표기부터 플레이스홀더 방식으로 처리하므로 `서울지방국세청` 이 `東京` + `지방국세청` 으로 쪼개지지 않습니다. 법조문은 값이 설명형 장문이라 치환 대상에서 제외됩니다.

## 📝 출력 포맷 — 企画モード (横書き)

| 항목 | 사양 |
|------|------|
| 용지 | A4 (210×297mm) |
| 방향 | 横書き (가로쓰기) |
| 폰트 | Yu Gothic (`w:eastAsia` 지정) |
| 씬 헤더 | `〇場所（時間帯）` — 〇 뒤 공백 없음 |
| ト書き | 3字下げ、現在形 |
| セリフ | `話者名「セリフ」` — 행걸이 들여쓰기, 문말 句点 없음 |
| 연속 대사 | `「セリフ」` 만 (話者名 반복 없음) |
| 인서트 | `インサート。` `【…】` `［…］` — ト書き 계열 |
| 출력 | DOCX + TXT 동시 |

> 촬영대본용 종서(縦書き 20字×20行) 포맷은 일본 공동제작사의 영역이므로 본 엔진의 범위에 포함하지 않습니다.

### 스타일 6종

`Hashira`(柱) · `Togaki`(ト書き) · `Serifu`(セリフ) · `SerifuCont`(연속 대사) · `Insert`(인서트) · `Tenkan`(전환)

전부 `w:eastAsia="Yu Gothic"` 이 지정되어 있습니다. 이게 없으면 한자·가나가 Word 기본 동아시아 폰트로 떨어져, 한 줄 안에서 숫자·영문만 다른 서체로 보입니다.

### DOCX 출력 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| 표지 페이지 생성 | ON | 첫 柱 앞 블록(제목·로그라인·작가·저작권번호)을 표지로 분리 |
| 페이지 번호 (푸터) | ON | 표지 제외, 하단 중앙 |
| 柱에 씬 번호 부여 | OFF | `〇1　場所（時間）` — 일본 企画モード 표준은 번호 없음 |
| 제작사 표기 | BLUE JEANS PICTURES | 표지 하단 |

### 출력 정규화

DOCX 쓰기 직전에 자동 후처리합니다.

- `〇 東京…` → `〇東京…`
- `高村 「…」` → `高村「…」`
- `水野（書類をめくり）「…」` → `水野「（書類をめくり）…」`
- `黒木（V.O.）「…」` → 그대로 유지 (V.O. / 声のみ / OFF / 電話 / 続き / ナレーション)

## 🎭 경어 톤 태그 (5단계)

| 태그 | 대상 | 특징 |
|------|------|------|
| `keigo` | 비즈니스, 경찰, 공식 관계 | です/ます + 敬語 |
| `teinei` | 초면, 서비스업, 일반적 거리감 | です/ます, 부드러운 톤 |
| `tameguchi` | 동등 관계, 친구, 독백 | だ/する, 축약형 |
| `kenson` | 위압적 상대에게 쓰는 겸양어 | いたします, 존경+겸양 |
| `ibar` | 갑질, 위에서 내려다보는 말투 | タメ口 + 명령형 |

관계 조합이 대사 역학을 결정합니다. `keigo ↔ ibar` 는 권력 불균형, `teinei ↔ teinei` 는 상호 거리, `tameguchi ↔ tameguchi` 는 대등입니다.

| JP-2 | 「〜している」 남용 | `確認している。ついている` → `確認する。ため息` |
| JP-3 | 감정 직접 서술 | `怒りを感じた` → `拳が白くなる` |
| JP-4 | 설명적 지문 | `落ち込んでいることを示す` → `未開封の郵便物。止まった時計` |
| JP-5 | セリフ 문말 단조 | 「ます」 연속 → バリエーション |
| JP-6 | 의성어 직역 | 한국 의성어 → 일본어 등가물 |
| JP-7 | 비트 중복 | `立ち止まる。間。静寂` → `間。` |
| JP-8 | 지문 3행 초과 | 분할하여 여백으로 템포 생성 |
| JP-9 | 문화적 직역 | 한국 정서 코드 → 일본 관객 등가물 |

### Stage 4 — DP-1 ~ DP-6

불완전한 문장 · 서브텍스트 우선 · 캐릭터 음성 차별화 · 리듬과 호흡 · 권력 역학 · 경어 레벨 일관성
